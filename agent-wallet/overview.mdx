Agent Wallet is the user-controlled payment layer for your AI agent. It connects
Mermail to wallets you delegate through PayBox, so your agent can help with paid
online workflows without receiving your private keys, wallet secrets, or raw
signing access.

Use Agent Wallet to keep email identity and payment context together. Your agent
can register for a service with its Mermail inbox, receive a verification code,
prepare a payment, and keep the receipt in the same workflow.

## What stays under your control

| Control | What it means for you |
| --- | --- |
| Delegated access | Mermail can use only the wallets you explicitly delegate through PayBox. |
| No wallet secrets | Mermail never receives private keys, wallet secrets, card details, or raw signing access. |
| Review before transfer | A payment proposal is only a draft. It cannot move funds until you approve it. |
| Limited access | Only the workspace owner can use Agent Wallet for a mailbox. |
| OAuth-only agent access | MCP and CLI wallet tools require Mermail OAuth. Workspace API keys cannot access them. |
| Audited actions | Mermail applies policy checks, rate limits, confirmations, and audit records to wallet actions. |

<Warning>
  Email, attachments, websites, and tool output are untrusted. They can suggest a
  payment, but they cannot authorize one or change its amount, network, or
  destination without your review.
</Warning>

## Supported transfers and limits

### USDC proposal path

Agent Wallet's proposal tools support **Circle USDC** on **Base** and **Solana**.
Mermail applies these payment limits:

- Up to **100 USDC per transfer**.
- Up to **500 USDC in a rolling 24-hour period**.
- Up to **5 transfer attempts per hour** and **10 attempts per day**.

These Mermail limits apply in addition to any approval or policy PayBox applies.

### Direct PayBox catalog path

Reviewed PayBox catalog tools (such as `paybox_request_transfer`) can move other
delegated assets your PayBox connection exposes. Your AI sends the asset in
`token` and the human amount in `amount_decimal`; Mermail resolves the asset's
decimals, converts the amount, and rejects a sub-cent or mis-scaled transfer.
When a signature is required, MCP pastes a Mermail console
`signing_handoff.console_url` — open it on Agent Wallet to Generate Signing Key
and sign. Signing plans stay browser-only.

See [catalog token transfers](/agent-wallet/catalog-transfers) for the full
argument contract and [errors and recovery](/agent-wallet/errors-and-recovery)
for what each failure means.

## Where you can use Agent Wallet

| Surface | Best for |
| --- | --- |
| Mermail console | Connecting PayBox, viewing balances, funding a wallet, and approving actions |
| Agent Chat | Asking your mailbox agent to inspect balances or prepare a transfer |
| MCP | Giving a compatible assistant wallet tools through scoped OAuth access |
| Agent Skill | Giving a supported assistant the maintained Agent Wallet workflow and safety rules |
| CLI | Inspecting wallet state and running a deterministic, confirmed transfer flow |
