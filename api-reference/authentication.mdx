Sold API endpoints require a Bearer credential scoped to a workspace. Console cookie sessions are for the Mermail app UI and do not replace an API key in Postman or the docs playground.

## Create an API key

<Steps>
  <Step title="Use a paid API plan">
    Developer (up to 5 keys) or Enterprise (unlimited). Free workspaces cannot create keys.
  </Step>
  <Step title="Open Settings → API Keys">
    Workspace admins can create, list, and revoke keys in the console.
  </Step>
  <Step title="Copy the secret once">
    The response includes `apiKey` (`mm_key_…`) and optional `clientSecret` (`mm_secret_…`). Mermail does not show the full key again.
  </Step>
</Steps>

## Call with Bearer

```bash
curl https://console.mermail.app/api/v1/workspaces \
  -H "Authorization: Bearer mm_key_YOUR_KEY"
```

In the docs playground, open any protected endpoint, click **Try it**, and paste the same value into the Bearer field. Prefill examples populate path and body fields so you can send immediately. Use the language dropdown to switch and copy snippets for **cURL, Python, JavaScript, PHP, Go, Java, or Ruby**.

## OAuth client credentials (optional)

If you stored `client_id` / `client_secret` from key creation:

```bash
curl -X POST https://console.mermail.app/api/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=mm_client_…&client_secret=mm_secret_…"
```

Use the returned `access_token` (`mm_at_…`) as Bearer. Tokens expire (default one hour).

## Manage keys via API

| Method | Path |
| --- | --- |
| `GET` | `/api/v1/workspaces/{workspaceId}/oauth-clients` |
| `POST` | `/api/v1/workspaces/{workspaceId}/oauth-clients` |
| `DELETE` | `/api/v1/workspaces/{workspaceId}/oauth-clients/{clientId}` |

These routes require a workspace **admin** and do not debit API credits.

## Console sessions (app only)

The Mermail console still uses first-party app cookies after identity sign-in. Cookie-authenticated browser mutations use CSRF protection. Prefer API keys for scripts, agents, and the docs **Try it** playground.

## Common errors

| Status | Meaning |
| --- | --- |
| `401` | Missing/invalid/expired/revoked key or token |
| `403` | Wrong workspace, Free plan (no keys), or missing role |
| `402` | API credits exhausted (`credits_exhausted`) |
| `429` | Workspace or user RPM exceeded |
