Most integrations should use a long-lived API key (`mm_key_…`) as Bearer instead.

Use this endpoint for **short-lived** `mm_at_…` tokens via client credentials — CI/CD, secret rotation, or avoiding a long-lived key in every service. See [Authentication](/api-reference/authentication).
