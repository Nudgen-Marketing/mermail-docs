Mermail's programmatic API is served under `/api/v1` (plus `/api/agent/mailbox` and `/api/oauth/token`).

| Access mode | Who | Auth |
| --- | --- | --- |
| **Public** | Every plan | None |
| **Console** | Every plan | Cookie session (Mermail app UI) |
| **Sold API** | Developer + Enterprise | Bearer `mm_key_…` or `mm_at_…` |

Free workspaces use the **console only**. They cannot create API keys, so they cannot call the sold catalog from Postman or this docs playground.

Developer and Enterprise share the **same sold endpoint list**. Enterprise differs by higher limits (keys, RPM, credits, resource quotas), not by extra customer-facing API paths.

## API access by plan

| Surface | Free | Developer | Enterprise |
| --- | --- | --- | --- |
| Public health / config | Yes | Yes | Yes |
| Console (cookie) | Yes | Yes | Yes |
| Create API keys | No (0 keys) | Yes (≤5) | Yes (unlimited) |
| Sold API + Bearer | No | Yes | Yes |
| Core sold catalog | — | Yes | Yes |
| Developer-gated sold APIs | — | Yes | Yes |
| API RPM (default) | 60 (console) | 300 | Unlimited |
| API credits / period | N/A for sold | 50,000 | Soft unlimited |

Full product limits: [Plans](/resources/plans).

## Free

Free includes **public** and **console** APIs only. There is **no** Bearer sold API.

### Public (no auth)

| Method | Path | Notes |
| --- | --- | --- |
| `GET` | `/api/status` | Health check |
| `GET` | `/api/v1/config` | Public client config |

### Console / bootstrap (cookie session)

These power the Mermail app. They do **not** use API credits. You call them from the console, not from an API key.

| Method | Path |
| --- | --- |
| `POST` | `/api/v1/auth/session` |
| `POST` | `/api/v1/auth/refresh` |
| `POST` | `/api/v1/auth/logout` |
| `GET` | `/api/v1/auth/me` |
| `POST` | `/api/v1/enoki/sponsor` |
| `POST` | `/api/v1/enoki/execute` |
| `GET` | `/api/v1/invites/{token}` |
| `POST` | `/api/v1/invites/{token}/accept` |
| `GET` | `/api/v1/billing/subscription` |
| `POST` | `/api/v1/billing/checkout` |

Mailbox, email, and workspace **UI** traffic may also hit `/api/v1/...` with a cookie. That is console usage (resource quotas apply). It is **not** the sold API product and Free cannot mint keys for Postman / Try it.

<Warning>
  Free cannot create API keys (`oauthClientLimit = 0`). Upgrade to Developer to use the sold API catalog below.
</Warning>

## Developer and Enterprise

Same sold paths. Auth: `Authorization: Bearer mm_key_…` (or `mm_at_…` from `POST /api/oauth/token`).

### Key management (admin, no credit debit)

Create the **first** key in **Settings → API Keys** (cookie). After that you can manage keys with Bearer too.

| Method | Path |
| --- | --- |
| `GET` | `/api/v1/workspaces/{workspaceId}/oauth-clients` |
| `POST` | `/api/v1/workspaces/{workspaceId}/oauth-clients` |
| `DELETE` | `/api/v1/workspaces/{workspaceId}/oauth-clients/{clientId}` |
| `POST` | `/api/oauth/token` |

### Developer-gated sold APIs (Developer + Enterprise)

Same for both paid plans. Free and missing Developer plan receive `403`.

| Area | Methods / paths |
| --- | --- |
| Custom domains | `GET/POST /workspaces/{id}/email-domains`, `DELETE …/{domainId}`, `POST …/verify` |
| Harbor storage write | `PUT …/storage`, `POST …/harbor-session`, `POST …/harbor-api-key` |
| Composio | `…/integrations/composio/toolkits`, `connections`, `calendar/account` |
| RAG write / credentials | `POST/DELETE /rag/documents…`, `POST /rag/credentials/*` |
| Task triage | `…/task-triagers`, `…/task-triager-runs/recent` |

## Try it or copy

Every endpoint page in the **API Reference** tab includes:

- Method + full URL
- Authorizations (Bearer)
- Path / query / body fields
- Response examples
- Language dropdown: **cURL, Python, JavaScript, PHP, Go, Java, Ruby**
- **Try it** against `https://console.mermail.app`

<Steps>
  <Step title="Upgrade to Developer or Enterprise">
    Free workspaces cannot create API keys. Open [Pricing](https://mermail.app/pricing).
  </Step>
  <Step title="Create an API key">
    Console → **Settings → API Keys** → copy `mm_key_…` once.
  </Step>
  <Step title="Open an endpoint">
    Use the sidebar groups for endpoints available on your plan.
  </Step>
  <Step title="Authorize and send — or copy">
    Click **Try it**, paste Bearer, fill params, send — or copy a snippet from the language dropdown.
  </Step>
</Steps>

<Tip>
  Start with **Public → Get API health status**, then **Usage → Get API credit usage** after you have a key.
</Tip>

## Authentication

| Credential | Header | How you get it |
| --- | --- | --- |
| API key | `Authorization: Bearer mm_key_…` | Settings → API Keys |
| Access token | `Authorization: Bearer mm_at_…` | `POST /api/oauth/token` |

See [Authentication](/api-reference/authentication).

## Credits (sold API)

| Class | Cost |
| --- | ---: |
| read | 1 |
| write | 2 |
| email_send | 5 |
| provision | 10 |
| ai_light | 15 |
| ai_heavy | 25 |

Developer returns `402` when the pool is empty. Enterprise soft-unlimited still records usage.

## Rate limits

Default workspace RPM: Free `60` (console), Developer `300`, Enterprise unlimited. Exceeding the limit returns `429`.
