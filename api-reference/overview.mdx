Use Mermail’s HTTP API from scripts, agents, Postman, or this docs **Try it** playground.

**Base URL:** `https://console.mermail.app`

All protected routes need:

```bash
Authorization: Bearer mm_key_YOUR_KEY
```

Create a key in the Mermail app under **Settings → API Keys**, then paste it into Try it or your client. See [Authentication](/api-reference/authentication).

Every Bearer call debits **API credits** and counts toward workspace **RPM**. When credits run out you get `402`; when you exceed RPM you get `429`.

Each endpoint page in this reference shows **plan badges** (sidebar tag + Plans line):

| Badge | Meaning |
| --- | --- |
| `Public` | No auth required |
| `All plans` | Free, Developer, and Enterprise |
| `Developer+` | Developer and Enterprise only (`403` on Free) |

## Plans at a glance

| | Free | Developer | Enterprise |
| --- | ---: | ---: | ---: |
| API keys | 1 | 5 | Unlimited |
| API credits / period | 1,000 | 50,000 | Soft unlimited |
| API RPM | 60 | 300 | Unlimited |
| Core API catalog | Yes | Yes | Yes |
| Developer-gated APIs | No (`403`) | Yes | Yes |

Full workspace limits (inboxes, email volume, storage): [Plans](/resources/plans).

Enterprise shares the same endpoint list as Developer — higher quotas, not extra customer paths.

## Quick start

<Steps>
  <Step title="Create an API key">
    In Mermail → **Settings → API Keys** → copy `mm_key_…` once (Free: 1 key, Developer: up to 5).
  </Step>
  <Step title="Pick an endpoint">
    Use the sidebar in this API Reference. Prefer core catalog endpoints on Free; Developer-gated paths need Developer or Enterprise.
  </Step>
  <Step title="Authorize and send">
    Open the page → **Try it** → paste Bearer → fill params → send. Or copy a **cURL / Python / JavaScript / PHP / Go / Java / Ruby** snippet from the language dropdown.
  </Step>
</Steps>

<Tip>
  Start with **Public → Get API health status** (no auth), then **Usage → Get API credit usage** with your key.
</Tip>

## Developer-gated APIs (Developer + Enterprise)

Free workspaces receive `403` on these paths. Upgrade to unlock them.

| Area | Paths |
| --- | --- |
| Custom domains | `GET/POST /workspaces/{id}/email-domains`, `DELETE …/{domainId}`, `POST …/verify` |
| Harbor storage write | `PUT …/storage`, `POST …/harbor-session`, `POST …/harbor-api-key` |
| Composio | `…/integrations/composio/toolkits`, `connections`, `calendar/account` |
| RAG write / credentials | `POST/DELETE /rag/documents…`, `POST /rag/credentials/*` |
| Task triage | `…/task-triagers`, `…/task-triager-runs/recent` |

## Credits

| Class | Cost |
| --- | ---: |
| read | 1 |
| write | 2 |
| email_send | 5 |
| provision | 10 |
| ai_light | 15 |
| ai_heavy | 25 |

Free and Developer return `402` (`credits_exhausted`) when the period pool is empty. Enterprise soft-unlimited still records usage. Check remaining balance via `GET /api/v1/workspaces/{workspaceId}/usage/credits`.
