Mermail offers Free, Developer, and Enterprise plans. Plan limits apply to each
workspace.

| Plan       | Price     | Best for                                                     |
| ---------- | --------- | ------------------------------------------------------------ |
| Free       | $0/month  | Trying Mermail with one agent inbox                           |
| Developer  | $19/month | Production agents and application workflows                  |
| Enterprise | Custom    | Custom scale, compliance requirements, or private deployment |

Review the current offer or start checkout on the [Mermail pricing page](https://mermail.app/pricing).

## Usage limits

| Limit                |          Free |     Developer | Enterprise |
| -------------------- | ------------: | ------------: | ---------: |
| Inboxes              |             1 |             5 |     Custom |
| Team members         |             1 |             5 |     Custom |
| Emails per month     |         1,000 |        10,000 |     Custom |
| Emails per day       | 100 per inbox | 100 per inbox |     Custom |
| Storage              |          1 GB |         10 GB |     Custom |
| Inbox pods           |             2 |            10 |     Custom |
| Webhook endpoints    |             2 |             5 |     Custom |
| Custom domains       |  Not included |             1 |     Custom |
| API keys             |             1 |             5 |  Unlimited |
| API RPM              |            10 |           100 |  Unlimited |
| API credits / period |         1,000 |        50,000 |  Unlimited |
| External API/MCP recipients per request | 10 | No special recipient cap | No special recipient cap |
| External API/MCP recipient windows | 10/min, 50/hour, 200/day | No special recipient windows | No special recipient windows |

<Info>
  Mermail notifies you when you approach your monthly email limit. Enterprise
  customers can arrange custom volume and overage terms. Sold API calls
  (`x-api-key`) debit API credits on every plan (Free included). Developer-gated
  endpoints still require Developer or Enterprise. See the [API
  overview](/api-reference/overview) for which endpoints each plan can call.
</Info>

The external recipient limiter counts every address in To+Cc+Bcc. It applies to
Free API/MCP `send_email`, `reply_to_email`, `forward_email`, and actual
scheduled delivery; in-app session sends bypass this special limiter. A
schedule is checked for the 10-recipient request cap when created, while rolling
quota is consumed when delivery runs. If rolling quota is exhausted, Mermail
restores the item to `scheduled` and defers it instead of claiming success.
Developer and Enterprise bypass only this special limiter and remain subject to
their normal RPM, API credit, monthly email, and other plan limits.

## Features

All plans include:

- Threads, labels, attachments, drafts, and scheduled sending.
- SDK and MCP server access.
- Websocket updates and SMTP relay.
- AI automation and a RAG database.
- Suppression lists and optimized shared IPs.
- Social sign-on and multi-factor authentication.
- Community support.

## Support and deployment

| Feature           | Free         | Developer    | Enterprise                      |
| ----------------- | ------------ | ------------ | ------------------------------- |
| Email support     | Not included | Included     | Priority                        |
| Slack channel     | Not included | Not included | Available                       |
| Launch onboarding | Not included | Not included | Available                       |
| Deployment model  | Shared cloud | Hosted cloud | Private or bring your own cloud |

Choose Enterprise when you need custom throughput, dedicated routing, private
deployment, SSO, procurement support, or a compliance review before agents can
process email.

<Warning>
  Enterprise availability does not by itself confirm a SOC 2 report, completed
  attestation, customer-owned storage, or zero data retention. Request current
  evidence and written scope from Mermail before relying on any compliance or
  retention capability.
</Warning>

## Change your plan

You can upgrade or downgrade from the Mermail console. Plan changes take effect
immediately and are prorated for the current billing cycle.
