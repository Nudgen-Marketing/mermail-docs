Mermail offers Free, Developer, and Enterprise plans. Plan limits apply to each
workspace.

| Plan       | Price     | Best for                                                     |
| ---------- | --------- | ------------------------------------------------------------ |
| Free       | $0/month  | Trying Mermail with two agent inboxes                        |
| Developer  | $10/month | Production agents and application workflows                  |
| Enterprise | Custom    | Custom scale, compliance requirements, or private deployment |

Review the current offer or start checkout on the [Mermail pricing page](https://mermail.app/pricing).

## Usage limits

| Limit             |          Free |     Developer | Enterprise |
| ----------------- | ------------: | ------------: | ---------: |
| Inboxes           |             2 |            10 |     Custom |
| Team members      |             2 |             5 |     Custom |
| Emails per month  |         1,000 |        10,000 |     Custom |
| Emails per day    | 100 per inbox | 100 per inbox |     Custom |
| Storage           |          3 GB |         10 GB |     Custom |
| Inbox pods        |             2 |            10 |     Custom |
| Webhook endpoints |             2 |             5 |     Custom |
| Custom domains    |  Not included |             5 |     Custom |

<Info>
  Mermail notifies you when you approach your monthly email limit. Enterprise
  customers can arrange custom volume and overage terms.
</Info>

## Features

All plans include:

- Threads, labels, attachments, drafts, and scheduled sending.
- SDK and MCP server access.
- Websocket updates and SMTP relay.
- AI automation and a RAG database.
- Suppression lists and optimized shared IPs.
- Social sign-on and multi-factor authentication.
- Community support.

| Feature              | Free                          | Developer              | Enterprise       |
| -------------------- | ----------------------------- | ---------------------- | ---------------- |
| AI automation        | Basic                         | Advanced               | Custom           |
| Metrics              | Basic                         | Developer metrics      | Custom reporting |
| Email domain         | Mermail-hosted domain         | Up to 5 custom domains | Custom domains   |
| DKIM, SPF, and DMARC | Managed on the Mermail domain | Included               | Included         |
| Signed webhooks      | Not included                  | Included               | Included         |
| Dedicated IPs        | Not included                  | Not included           | Contact Mermail  |
| White-label options  | Not included                  | Not included           | Available        |
| EU cloud             | Not included                  | Not included           | Available        |
| Bring your own cloud | Not included                  | Not included           | Available        |
| SOC 2 report         | Not included                  | Not included           | Available        |
| OIDC or SAML SSO     | Not included                  | Not included           | Available        |

## Support and deployment

| Feature           | Free         | Developer    | Enterprise                      |
| ----------------- | ------------ | ------------ | ------------------------------- |
| Email support     | Not included | Included     | Priority                        |
| Slack channel     | Not included | Not included | Available                       |
| Launch onboarding | Not included | Not included | Available                       |
| Deployment model  | Shared cloud | Hosted cloud | Private or bring your own cloud |

Choose Enterprise when you need custom throughput, dedicated routing, private
deployment, SSO, procurement support, or a compliance review before agents can
process email.

## Change your plan

You can upgrade or downgrade from the Mermail console. Plan changes take effect
immediately and are prorated for the current billing cycle.
