Use Mermail for a specific goal, from buying one xStock through Agent Wallet to
researching prospects or setting up a support inbox for your brand. Each guide
explains what you need, how to run the workflow, and what to check before you
finish.

## Start with the right setup

- **A mailbox:** [Create a mailbox](/guides/create-mailbox) and choose the
  [workspace](/concepts/workspaces) that owns the workflow.
- **An assistant connection, when needed:** For workflows in an external AI
  assistant, [connect Mermail through MCP](/ai/mcp). The assistant's available
  tools depend on the connection and your permissions.
- **An Agent Skill, when needed:** Install the focused workflow from
  [Mermail Skills](/ai/skills). The xStocks workflow requires
  `mermail-xstocks-desk` and the default full MCP profile with OAuth.
- **Agent Wallet, when needed:** [Set up Agent Wallet](/agent-wallet/get-started)
  before buying an xStock or using a paid research service. Customer support
  website setup does not require Agent Wallet.

## What to expect from a guide

Use the example prompts as starting points. Replace the audience, sender,
business details, and budget with your own requirements. Check the selected
mailbox and any proposed external action before approving it.

Research results, saved emails, and sent emails are separate outcomes. A paid
research request does not send outreach, and preparing an email does not mean
it has been sent. Each guide includes checks for its final result.
